Discoveries Battleship Game

Projeto Java/Maven da Batalha Naval com documentação automática e suporte Docker.

Sobre o projeto

Este projeto implementa uma versão do jogo Batalha Naval em Java. Usa Maven para compilação, gestão de dependências e geração de documentação técnica.

Documentação

A documentação do projeto está dividida entre o site Maven e os Javadocs da aplicação.

Site Maven Javadocs

Execução com Docker

A aplicação pode ser compilada e executada através de uma imagem Docker local. 

docker build -t battleship-game:latest .
docker run -it --rm battleship-game:latest
